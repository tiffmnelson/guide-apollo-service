## Overview

To create a genome track in your Apollo Instance, you must upload:

1. **Mandatory files**: Genome reference (FASTA), index (FAI), and annotation (GFF3, GFF3.gz)
2. **Optional evidence files**: Alignments (BAM), variants (VCF), coverage (BigWig)

This guide covers data preparation, file formats, and upload methods.

## Required File Formats

| File Format | Description | Requirement | Notes |
|-------------|-------------|-------------|-------|
| FASTA | Genome reference sequence | Mandatory | `.fa`, `.fna`, or `.fasta` extension |
| FAI | Genome reference index | Mandatory | Generated by `samtools faidx` |
| GFF3 | Genome annotation | Mandatory | Gene predictions and features |
| GFF3.gz | Compressed annotation | Mandatory | Generated by `bgzip` and `tabix` |
| 2bit | Binary genome sequence | Optional | Generated by `faToTwoBit` |
| BAM | Alignment file | Optional | RNA-seq, DNA-seq alignments |
| BAI | Alignment index | Optional | Generated by `samtools index` |
| VCF | Variant calls | Optional | SNPs, indels, structural variants |
| VCF.gz | Compressed variants | Optional | Generated by `bgzip` and `tabix` |
| BigWig | Genome-wide signal | Optional | Coverage, expression, other signals |
